NAVODILA ZA VZPOSTAVIT BAZE:

Kot pri vajah PB uporabljamo Docker in DataGrip.

1. Git pull

2. V repozitoriju v mapi baza-setup odpri cmd 
	
	2.1 Zaženi ukaz "docker compose up -d"
		
		V Dockerju bi se ti moral ustvarit now container "baza-setup" ali "praktikum"
		Če imaš v dockerju druge containerje na portu 5432 jim spremeni port ali izbriši

	2.2 Preveri če dela z ukazom "docker ps" 
		
		Status mora biti "up"

3. V DataGripu dodaj novi database source - postgreSQL in v oknu properties, ki se ti odpre izpolni sledeče:

	Name: praktikum_baza@localhost
	
	General-
		Host: localhost 
		Port: 5432

		Authentication: User & Password
		User: admin
		Password: geslo123
		Save: Forever
		
		Database: praktikum_baza

		URL: jdbc:postgresql://localhost:5432/praktikum_baza

	3.1 Ko so podatki vneseni jih shrani in potem v istem oknu spodaj stisni "Test Connection", mora ti vrnit "Succesful"
	    Če ti vrne "failed" poglej error, če piše databse doesnt exist mogoče nisi v pravi mapi zagnal cmd ali pa si narobe prepisal ime baze, ki je "praktikum_baza"
	    Preveri tudi, če je v dockerju container zagnan, če ni ga zaženi.

4. V DataGripu bi se ti moralo odpret okno console, kjer lahko zdaj zaženeš sledeče ukaze, ki bi morali vrnit baze:

	SELECT * FROM Naslov;
	SELECT * FROM Uporabnik;
	SELECT * FROM Ekipa;
	SELECT * FROM Uporabnik_Ekipa;
	SELECT * FROM Prizorisce;
	SELECT * FROM Dogodek;
	SELECT * FROM Udelezba;
	SELECT * FROM Mnenje;
